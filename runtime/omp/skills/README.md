# Bundled OMP skills

Imported from Teck.Paseo with the application lifecycle skills replaced by
`orca-cli`, `orchestration`, `orca-workers` and `orca-feature-workflow`.
The CLI and orchestration skills include complete guides and their references
from the installed Orca CLI. Refresh deliberately with `npm run bundle:skills`
on the desktop, then build and setup. Guest terminals prefer their live CLI's
matching guides. Technical skills retain their original instructions; GitHub
execution planning uses the Orca workflow. Load only relevant skills.

The always-loaded RULES.md routes leads to orca-feature-workflow. That entry point
routes each role/stage instead of preloading all coordination references.
github-execution-planning/references/issue-structure.md owns issue decomposition
and blocker decisions; review-gates.md owns the corresponding review paths.
Load placement/recovery, label catalogs and PR-stack details only at their action
gates. Keep official Orca snapshots unchanged when updating Teck policy.
